# 第 05 章 · 思考题

## 思考题

1. ReAct 与 ReWOO 在「中间结果决定下一步」的任务上，哪个更合适？为什么？
2. LLM+P 把规划交给经典 planner，那么 LLM 的真正价值在哪？
3. 在你的导航业务里，能不能让 LLM 先生成一份 *结构化任务计划*（路径段 + 工具调用），交给底层执行器？
4. ReWOO 的 Planner 错了怎么办？设计一个最少 LLM 调用的「错误恢复」机制。

## 面试题

1. **(基础)** 解释 Plan-and-Solve 与 zero-shot CoT 的区别。
2. **(深入)** ReWOO 的 token 节省主要来自哪？给出一个简单的 token 复杂度分析。
3. **(系统)** 设计一个混合 planner：简单 query 走 ReAct，复杂 query 自动升级到 ReWOO。如何判断「复杂」？
4. **(开放)** OpenAI o1/o3 等强推理模型出现后，「显式 plan」是否还有必要？哪些场景仍然需要？
