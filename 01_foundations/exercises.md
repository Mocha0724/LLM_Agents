# 第 01 章 · 思考题与面试题

## 思考题

1. 用 PEAS 框架描述「高德地图导航 App」是不是一个 agent。
2. 给定一个固定 5 步的 RAG pipeline，它属于 workflow 还是 agent？为什么？
3. 一个 *视觉重定位* 任务（输入图像 + IMU，输出位姿）能否抽象为 agent？哪些步骤适合让 LLM 介入，哪些不适合？

## 面试题

1. **(基础)** 解释 CoT、ReAct、Reflexion 三者的区别。
2. **(开放)** 为什么 2024-2026 年「agent 框架」如此泛滥？这种繁荣有哪些隐忧？
3. **(系统设计)** 设计一个「电商客服 agent」，请画出系统架构，并说明哪些环节用 workflow、哪些用 agent。
4. **(深入)** 假设一个 agent 在长程任务中越走越偏，有哪些工程手段可以拉回？（提示：约束动作空间、reflection、人在回路、step budget）
